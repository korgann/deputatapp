# ДепутатApp

Flutter-приложение для прямого взаимодействия избирателей с депутатами маслихатов и Курултая: задать вопрос своему депутату, записаться на приём, участвовать в опросах и видеть публичный рейтинг по доле закрытых обращений.

> **Статус: прототип.** Бэкенда нет — все данные хранятся в памяти и сбрасываются при перезапуске. SMS-код, вход и распознавание роли по ИИН смоделированы (см. [Демо-режим](#демо-режим)). Депутаты, вопросы и посты в приложении — вымышленные демонстрационные данные.

## Возможности

**Для избирателя**
- Регистрация по ИИН, телефону и адресу с подтверждением по SMS и PIN-кодом
- Автоматическая привязка к своим депутатам по городу, области и номеру округа
- Вопросы депутату с отслеживанием статуса: `ожидает` → `в работе` → `отвечен`, лайки чужих вопросов
- Голосование в опросах — один голос на пользователя, до дедлайна
- Запись на приём к депутату на конкретную дату и время
- Лента блога депутатов, рейтинги и топ-10, карта по регионам

**Для депутата**
- Отдельная регистрация с партией, должностью, организацией и номером округа
- Ответы на вопросы с отметкой «обращение закрыто» — она влияет на рейтинг
- Публикация постов с тегами и создание опросов с дедлайном

**Общее**
- Фильтр нецензурной лексики применяется к вопросам, ответам и постам перед сохранением
- Уведомления о новых вопросах, ответах, опросах и напоминания о приёме

## Как это устроено

**Привязка депутатов** ([deputy_binder.dart](lib/core/utils/deputy_binder.dart)) — избиратель видит своих депутатов по месту жительства:

| Где живёт | Сколько депутатов | Какие |
| --- | --- | --- |
| Астана, Алматы, Шымкент | 2 | городской маслихат + Курултай |
| Остальные регионы | 3 | районный + областной маслихат + Курултай |

**Рейтинг** ([deputy_model.dart](lib/core/models/deputy_model.dart)) — основной показатель `ratingScore` считается как доля закрытых обращений: `completedQuestions / totalQuestions * 100`. Рядом хранятся оценка избирателей, месячный и годовой баллы. Экран рейтингов сортирует депутатов по `ratingScore`.

**Состояние** — единый [`AppProvider`](lib/core/providers/app_provider.dart) на `ChangeNotifier` держит пользователя, депутатов, вопросы, посты, опросы, записи на приём и уведомления. Никаких HTTP-клиентов и SDK бэкенда в зависимостях нет.

## Стек

Flutter, Dart SDK `^3.12.2`. Зависимости: `provider` (состояние), `shared_preferences`, `table_calendar` (выбор даты приёма), `intl` (даты), `cupertino_icons`. Платформы в репозитории: Android, iOS, Web, Windows.

## Демо-режим

Пока бэкенда нет, вход работает по упрощённым правилам — это заглушки, а не реальная проверка:

- **SMS-код всегда `1234`** — реальная отправка не подключена
- **Роль определяется по ИИН**: начинается на `99` — депутат, иначе избиратель
- **Вход** проходит при любом телефоне от 10 цифр, ИИН ровно из 12 цифр и PIN из 4 цифр; данные профиля подставляются демонстрационные

## Что нужно для боевой версии

Прототип намеренно не решает эти задачи:

- Реальный бэкенд и постоянное хранилище вместо данных в памяти
- Настоящая верификация личности по ИИН и отправка SMS вместо кода `1234`
- Хранение PIN в виде хеша, а не открытой строкой в модели пользователя
- Реальный справочник депутатов и округов вместо демонстрационного списка
- Карта на картографическом SDK — сейчас это выбор региона из списка, а не настоящая карта
